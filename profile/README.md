# QA Filt Viasoft

Equipe de qualidade de software do **Filt**, o ERP da Viasoft.

## O que fazemos

- Planejamos e executamos testes funcionais, de regressão e de integração.
- Escrevemos casos de teste em BDD (Gherkin), com rastreabilidade entre requisito, caso e evidência.
- Investigamos defeitos e documentamos o comportamento esperado do sistema.
- Mantemos a base de conhecimento que apoia a validação das entregas.

## Como trabalhamos

- Cada entrega é validada contra o requisito, e o resultado fica registrado com evidência.
- Os achados viram issues rastreáveis, com contexto suficiente para reprodução.
- Automatizamos o que se repete e revisamos o que automatizamos.
